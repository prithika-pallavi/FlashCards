# FlashCards
A full-stack French learning flashcard app that helps beginners practice vocabulary through interactive and randomized flashcards. Built with both frontend and backend integration to provide a smooth and engaging learning experience.

# Flashy - French Flashcard App

A simple flashcard app built with Python and Tkinter to help users learn French vocabulary. The app shows a French word and flips the card after a few seconds to display the English meaning.

## Features

* Random French flashcards
* Auto card flip after 3 seconds
* Mark words as known
* Saves learning progress
* Simple GUI using Tkinter

## Tech Used

* Python
* Tkinter
* Pandas

## Run the Project

Install pandas:

```bash
pip install pandas
```

Run the app:

```bash
python main.py
```

## Project Purpose

Built to practice Python GUI development, file handling, and working with CSV data.
